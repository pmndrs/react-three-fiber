# useRenderPipeline

Declarative WebGPU render pipeline setup with automatic scene pass and MRT configuration.

```ts
import { useRenderPipeline } from '@react-three/fiber/webgpu'
```

📖 **Full documentation:** https://docs.pmnd.rs/react-three-fiber/webgpu/render-pipeline

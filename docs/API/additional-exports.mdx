| `createPortal`       | Creates a portal (it's a React feature for re-parenting)       |
| `createRoot`         | Creates a root that can render three JSX into a canvas         |
| `events`             | Dom pointer-event system                                       |
| `applyProps`         | `applyProps(element, props)` sets element properties,          |
| `act`                | usage with react-testing                                       |
| `useInstanceHandle`  | Exposes react-internal local state from `instance.__r3f`       |

## Prop Utilities

v10 adds two utilities for common prop patterns that previously required imperative code.

### `fromRef` — deferred ref resolution

`fromRef` defers prop application until a ref is populated. This is essential for props like `target` that reference sibling elements, replacing the old mount-time `useEffect`:

```tsx
import { fromRef } from '@react-three/fiber'

function SpotlightWithTarget() {
  const targetRef = useRef<THREE.Object3D>(null)
  return (
    <>
      <group ref={targetRef} position={[0, 0, -10]} />
      {/* target resolves after targetRef is populated */}
      <spotLight target={fromRef(targetRef)} intensity={100} />
    </>
  )
}
```

### `once` — mount-only method calls

`once` marks a method prop to be applied only on initial mount, which is useful for geometry transforms that shouldn't compound every render:

```tsx
import { once } from '@react-three/fiber'

// Rotate geometry 90° on mount (without `once` this compounds every render)
<boxGeometry args={[1, 1, 1]} rotateX={once(Math.PI / 2)} />

// Center geometry on mount
<bufferGeometry center={once()} />

// Apply a matrix on mount
<bufferGeometry applyMatrix4={once(transformMatrix)} />
```

When `args` change (triggering element reconstruction), `once` methods run again on the new instance.
